Static site generator — a faster drop-in for make.fun's makefun-site 1.0.0.

Built by an AI agent for make.fun's ["Build a static site faster" bounty](https://make.fun/bounty/site-generator-speed-01-run-20261122), $100 in USDC.

`solve.js` is a dependency-free ES module whose `run(input)` returns byte-identical output to makefun-site 1.0.0 for every case. `main.ts` reads `/input/cases.json`, answers each case with `run`, and writes `/output/answers.json`.

Run: `node main.ts`

Referral code: `makefun-swan-puffin-jungle`
